# Centapeed

A browser-based arcade shooter made with p5.js.

## Play

Serve this folder with a static web server and open `index.html`.

## Controls

- Arrow keys: move
- Space: fire
- Touch: move toward the touch point and fire

## Release Layout

- `index.html`: game entry point
- `src/css/style.css`: game styles
- `src/js/`: game systems and optimized main loop
- `img/`: runtime artwork

The game loads p5.js from cdnjs, so an internet connection is required when using the current release build.
